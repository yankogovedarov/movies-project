# Система за проследяване на гледани филми

Локално уеб приложение за каталогизиране на филми от външен диск, проследяване на това кои са гледани и стартиране в VLC директно от браузъра.

## Статус

🟢 **v1.0.1 — в продукшън** · 🟡 **v1.11.0 — в разработка (`develop`)** — MVP-1 и MVP-2 завършени (Итерации 01–22) и разгърнати на диска; v1.0.1 добавя поправки и подобрения (итерации 23–25, маркиран с анотиран git таг `v1.0.1`). В `develop` версията е вдигната на **v1.11.0** (Bug #16–#24, #26, #27, #30 → итерации 26–44); ще стане продукшън при сливане в `master` и нов таг.

> **Бранч стратегия:** `master` = продукшън (текущо: `v1.0.1`). Нови функции се разработват в бранч `develop` (текущо: `v1.11.0`) и се сливат в `master` при следващ релийс (с нов таг). Виж [docs/Архитектура.md §9.1](docs/Архитектура.md).

## Бързо стартиране (за разработчици)

```sh
# Инсталирай dev инструменти (templ, sqlc, air, golangci-lint)
task install

# Стартирай с hot reload
task run

# Пусни тестове (не отварят VLC, Explorer или браузър)
task test

# Пусни browser E2E тестовете
task test:e2e

# Стартирай .exe без да пуска VLC/Explorer/браузър (ползва се от e2e)
$env:MOVIETRACKER_NO_LAUNCH = "1"; bin\movietracker.exe

# Билдвай production .exe (изходът отива в bin/, увеличава build номера)
task build

# Провери версията без пълно стартиране
bin\movietracker.exe --version
```

**За потребители:** Копирай `bin\movietracker.exe` в папка `MovieTracker\` на диска → двойно кликни → отвори браузъра на `http://localhost:8080`.
