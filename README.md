# Система за проследяване на гледани филми

Локално уеб приложение за каталогизиране на филми от външен диск, проследяване на това кои са гледани (от кого) и стартиране в VLC директно от браузъра.

## Статус

🟡 **Фаза: разработка в ход** — Итерация 12 завършена. MVP-1 почти готов (остава Итерация 13: polish).

### Завършени функционалности (MVP-1)

| Функция | Итерация |
|---------|----------|
| ✅ Рекурсивно сканиране на диск (`.mkv`, `.avi`, `.mp4`) | 03–05 |
| ✅ Sample филтриране (< 50 MB se пропускат) | 04 |
| ✅ SQLite база данни + миграции + sqlc | 06 |
| ✅ Синхронизиране на scan резултати → DB | 07 |
| ✅ Плосък списък на медии (`GET /`) | 08 |
| ✅ VLC detection + per-computer config | 09 |
| ✅ Стартиране на медия → VLC + event log (`POST /media/:id/start`) | 10 |
| ✅ Промяна на статус + dropdown UI (`POST /media/:id/status`) | 11 |
| ✅ Фоново сканиране + бутон "Сканирай" (`POST /scan`) | 12 |

## Бързо стартиране (за разработчици)

```sh
# Инсталирай dev инструменти (templ, sqlc, air, golangci-lint)
task install

# Стартирай с hot reload
task run

# Пусни тестове
task test

# Билдвай production .exe
task build
```

**За потребители:** Копирай `movietracker.exe` в папка `MovieTracker\` на диска → двойно кликни → отвори браузъра на `http://localhost:8080`.
