# Система за проследяване на гледани филми

Локално уеб приложение за каталогизиране на филми от външен диск, проследяване на това кои са гледани (от кого) и стартиране в VLC директно от браузъра.

## Статус

🟡 **Фаза: анализ и планиране** — заданието е готово, архитектурата предстои.

## Контекст

Външен диск с **~538 видео файла (~436 GB)** се мести между 3 Windows компютъра (10/11). Двама потребители (Янко и Лиза) гледат заедно или поотделно. Целта е една обща история на гледането, която живее на самия диск и пътува с него.

## Основни функции (MVP)

1. **Сканиране на диска** — всички top-level папки без изключените (Books, Games, Install и т.н.)
2. **Стартиране на медия от UI** — кликаш → VLC се отваря; записва се дата/час
3. **Статус на медия** — 5 възможни (Нова, Стартирана, Завършена от двамата/Янко/Лиза)
4. **Преглед с филтри** — по статус и по наличност (на диска / липсваща)
5. **Преглед по структура на диска** — йерархичен изглед на папките
6. **Детайлен изглед** — пълна история на стартиранията и промените на статуса
7. **Авто-стартиране** при свързване на диска

## Технически принципи

| Тема | Решение |
|------|---------|
| Идентификация на медия | Име на файла + размер в байтове |
| Откриване на диска | Файл-маркер `.movie-tracker-disk` в корена |
| Данни | Един файл на самия диск (преносим backup) |
| VLC | Не се следи — записваме само при кликане в UI |
| Sample файлове | Авто-пропускане (<50 MB при наличие на по-голям видеофайл) |
| Език на UI | Български |

## Изключено от обхвата

- Без интернет / cloud синхронизация — приложението работи изцяло офлайн
- Без поддръжка на Windows 8
- Без метаданни от външни услуги (постери, рейтинги)
- Без проследяване на прогрес в самия филм
- Без следене на VLC извън нашия UI
