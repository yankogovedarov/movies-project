# Система за проследяване на гледани филми

Локално уеб приложение за каталогизиране на филми от външен диск, проследяване на това кои са гледани (от кого) и стартиране в VLC директно от браузъра.

## Статус

🟢 **Фаза: готов за разработка** — задание, архитектура и решения са финализирани.
