# Итерация 31 — Бъг 18 (1): семпло поле за търсене

## Цел

Полето за търсене в горната лента е визуално твърде „тежко":
- по-високо е от останалите елементи (icon бутони, надписи, филтри);
- съдържа **две иконки** — 🔍 емоджи в `placeholder`-а и нативния бутон за изчистване
  (✕, `::-webkit-search-cancel-button`), който се появява при въвеждане на текст.

Желано поведение (по заданието на Бъг 18): контролът да е **семпъл** — еднаква
височина с останалите елементи на лентата и **без иконки**.

## Обхват

- Само `templates/list.templ` (+ регенериран `list_templ.go`).
- **Не** се променя `type="search"` — HTMX live търсенето (`hx-trigger="search"`) и
  съществуващите Go/e2e тестове разчитат на `input[type=search][name=q]`.

## Решение

1. **Махане на 🔍 от placeholder** → `placeholder="търси..."` (премахва иконка №1).
2. **Скриване на нативните search декорации** чрез CSS на `.search-input`:
   - `appearance: none` / `-webkit-appearance: none` — маха нативния search вид;
   - `::-webkit-search-cancel-button`, `::-webkit-search-decoration { display: none }`
     — маха бутона за изчистване (иконка №2).
3. **Изравняване на височината** с останалите елементи на лентата (icon бутоните са
   `1.35rem`): `box-sizing: border-box; height: 1.35rem; line-height: 1.35rem; margin: 0`.
