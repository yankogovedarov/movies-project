# Итерация 27 — Бъг 16 (част 4)

## Обхват

**Текстовото търсене да работи докато се въвежда текстът — без натискане на Enter.**

Полето за търсене (`input[name=q]`) получава HTMX атрибути, които задействат заявка
при писане (с дебоунс), извличат само обновения списък и го разменят на място. Адресът
се обновява (`hx-push-url`), така че презареждане/споделяне на URL запазва търсенето.

## Подход

- Резултатната секция се обвива в `<div id="media-list">` (празно състояние + таблицата).
- Полето за търсене:
  - `hx-get="/"` — заявка към списъчния handler (връща пълната страница).
  - `hx-trigger="keyup changed delay:300ms, search"` — при писане (дебоунс 300ms) и при
    изчистване на полето (`search` събитието на `type=search`).
  - `hx-include="closest form"` — пренася активните филтри (status/disk/sort/dir/trans) + `q`.
  - `hx-target="#media-list"` + `hx-select="#media-list"` + `hx-swap="outerHTML"` — взима само
    `#media-list` от отговора и подменя текущия.
  - `hx-push-url="true"` — синхронизира адреса.
- Формата запазва `method="GET" action="/"` като fallback без JavaScript (Enter още работи).

## Файлове за промяна

- `templates/list.templ` — обвиване на резултатите в `#media-list`; HTMX атрибути на полето за търсене.
- `internal/web/handlers_goquery_test.go` — `TestIndex_SearchInput_IsLive`: полето има `hx-get`,

- `tests/e2e/test_filters.py` — e2e проверка че полето за търсене има live `hx-trigger`.
