# Итерация 21 — Бъг 12: Сортиране по път/размер + посока + случаен филм

## Цел

Реализация на четирите изисквания от Bug #12:

1. Добавяне на сортиране по **път на файла** (папка)
2. Добавяне на сортиране по **размер на файла**
3. Всеки бутон за сортиране сортира **възходящо** при първо натискане и **низходящо** при второ; посоката е визуално откроена
4. Нова функция **"Стартирай случаен нов филм"** — малка иконка в горната лента

---

## Дизайнерски решения

### Посока на сортиране

Добавя се нов URL параметър `dir` (`asc` | `desc`), по подразбиране `asc`.

Логика на бутоните:
- Натискане на **неактивен** бутон → URL с `dir=asc`
- Натискане на **активен** бутон при `dir=asc` → URL с `dir=desc`
- Натискане на **активен** бутон при `dir=desc` → URL с `dir=asc`

Визуален индикатор: активният бутон показва `↑` (asc) или `↓` (desc) добавен след иконката. Бутонът получава `width: auto; min-width: 1.35rem; padding: 0 0.2rem`, за да побере двата символа.

### Нови сортировъчни бутони

| Бутон | `sort=` | Иконка | Описание |
|-------|---------|--------|----------|
| Път   | `path`  | `Пт`   | По `FolderRelativePath`, азбучно |
| Размер | `size` | `Рз`   | По `FileSizeBytes`, числово |

### Случаен нов филм

- Endpoint: `POST /media/random-new/start`
- Handler: избира произволна медия с `current_status = "new"` и `on_disk = 1`
- Стартира в VLC, сменя статуса `new → started`, записва start event
- Редиректира към `/` (без HTMX — цялата страница се обновява)
- Бутон в navbar: `🎲` иконка (форма с `POST`, styled като `.sort-btn`)
