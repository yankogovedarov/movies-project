# Итерация 17: Детайлен изглед с история

## Цел

Добавяне на `GET /media/:id` страница с пълна информация за медия и хронологична история на стартиранията и промените на статус.

## Мотивация

Към момента потребителят може само да вижда списък и дърво — няма начин да разгледа пълната история на конкретна медия. DB схемата вече съдържа `start_events` и `status_changes` таблици. Тази итерация ги визуализира.

## Промени

### SQL (`internal/db/queries.sql`)
- `GetStartEvents :many` — всички стартирания за медия, DESC
- `GetStatusChanges :many` — всички промени на статус за медия, DESC

### Handler (`internal/web/handlers.go`)
- `MediaDetail` — зарежда медия + история, рендира `DetailPage`

### Темплейт (`templates/detail.templ`)
- Хедър с navigation, информация, бутони Стартирай/Смени статус
- Таблица "История на стартиранията"
- Таблица "История на статусите"
- Бутоните са disabled ако `on_disk == 0`

### Навигация (`templates/list.templ`)
- Filename бутонът → `<a href="/media/{id}">` (детайлна страница вместо директен старт)

### Route (`cmd/movietracker/main.go`)
- `r.GET("/media/:id", h.MediaDetail)`

### Тестове
- 3 нови unit теста в `handlers_test.go`
- 2 нови goquery теста в `handlers_goquery_test.go`
- E2E: `tests/e2e/test_detail_page.py`

## Дефиниция за готово

- `go test ./...` → всички тестове минават
- `go build` → без грешки
- Кликване върху файл от списъка → отваря детайлна страница
- Детайлната страница показва история на стартиранията и статусите
