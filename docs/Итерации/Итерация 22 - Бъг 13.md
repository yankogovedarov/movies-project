### Стъпка 3 — Handler промени (`internal/web/handlers.go`)

#### 3a. Helper функция `filterMedia`

```go
func filterMedia(raw []db.Medium, statusFilter, qFilter, transFilter string) []db.Medium {
    result := raw
    if statusFilter != "all" {
        f := make([]db.Medium, 0, len(result))
        for _, m := range result {
            if m.CurrentStatus == statusFilter { f = append(f, m) }
        }
        result = f
    }
    if qFilter != "" {
        q := strings.ToLower(qFilter)
        f := make([]db.Medium, 0, len(result))
        for _, m := range result {
            if strings.Contains(strings.ToLower(m.Filename), q) ||
               strings.Contains(strings.ToLower(m.FolderRelativePath), q) {
                f = append(f, m)
            }
        }
        result = f
    }
    if transFilter != "all" {
        f := make([]db.Medium, 0, len(result))
        for _, m := range result {
            if m.TranslationType == transFilter { f = append(f, m) }
        }
        result = f
    }
    return result
}
```

#### 3b. Index handler

- Добавяне на `qFilter := c.DefaultQuery("q", "")` и `transFilter := c.DefaultQuery("trans", "all")`
- Замяна на inline статус-филтър с `filterMedia(raw, statusFilter, qFilter, transFilter)`
- Актуализиране на `templates.ListPage(…)` с нови параметри

#### 3c. RandomNew handler

- Чете `status`, `disk`, `q`, `trans` от POST body (`c.PostForm(…)`)
- Извиква `filterMedia(raw, status, q, trans)` вместо inline "само нови"
- Редиректва към `/?status=…&disk=…&q=…&trans=…` (запазва активния изглед)

#### 3d. Нов SetTranslationType handler

- Маршрут: `POST /media/:id/translation-type`
- Чете `type` от POST body (`sub`, `bg`, `orig` или `""` за изчистване)
- Извиква `q.UpdateTranslationType(ctx, ...)`
- При HTMX заявка: връща `<tr>` фрагмент
- Иначе: redirect към `/`
