# Итерации — правила и план

## Workflow правила

| Параметър | Избор |
|-----------|-------|
| Стил | **TDD-strict slices** — всяка итерация започва с failing test, после имплементация |
| Test policy | **TDD (test-first)** |
| Размер на итерация | **Малки (1-2 часа)** |
| Планиране | В plan mode преди всяка итерация — изпълнение само след одобрение |

### Правила за всяка итерация

1. **Преди старт** — plan mode: дефинираме failing tests + implementation scope
2. **Изпълнение ВИНАГИ:**
   - Failing test(ове) първо (red)
   - Минимална имплементация → green
   - Refactor ако е нужен
   - Верификация: `go test ./...`, `go build`, ръчен тест ако е приложимо
   - Commit: `Итерация NN: <feature>`
3. **Vertical slicing** — всяка итерация дава работещ end-to-end функционал
4. **Без scope creep** — извън обхвата → записва се за бъдеща итерация
5. **Детайлният план** на всяка итерация се пази в отделен файл `Итерация NN - <name>.md`
