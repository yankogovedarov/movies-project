# Итерация 19: Сортиране и обогатен списък

## Цел

Добавяне на сортиране в плоския списък (`GET /`) + показване на "Последно стартирана на X (N пъти)" под всяко заглавие. Потребителят избира реда чрез икон-бутони в навигацията.

## Мотивация

При много медии потребителят иска да открие наскоро гледани или добавени файлове. Обогатената информация в реда дава контекст без да отваря детайлния изглед.

## Промени

### Нов файл `internal/db/stats.go`
- Ръчна (не-sqlc) SQL функция `FetchMediaStats(ctx, db) (map[int64]MediaStats, error)`
- Агрегирана заявка с LEFT JOIN към `start_events` и `status_changes`
- Връща: `last_started_at sql.NullTime`, `start_count int64`, `marked_at sql.NullTime` per media ID
- `FetchSingleMediaStats(ctx, db, id) (MediaStats, error)` — за HTMX row updates

### Нов тип `MediaWithStats` в `internal/web/handlers.go`
```go
type MediaWithStats struct {
    db.Medium
    LastStartedAt sql.NullTime
    StartCount    int64
    MarkedAt      sql.NullTime
}
```

### Handler (`internal/web/handlers.go`)
- `Index` чете `?sort=` (default `name`; стойности: `name`, `last_started`, `added`, `marked`)
- Извиква `FetchMediaStats`, обединява с media slice в `[]MediaWithStats`
- Сортира в Go по избрания ключ (nulls last за nullable полета)
- Предава `sortFilter` на `ListPage`
- `StartMedia` и `ChangeStatus` — след обновяване извикват `FetchSingleMediaStats` и рендират `MediaRow(MediaWithStats)`

### Темплейт (`templates/list.templ`)
- `MediaRow` сигнатура: `(m MediaWithStats)` (import от `web` package или вграден тип)
- Ред в таблицата показва под filename: `"Стартирана N пъти, последно на ДД.ММ.ГГГГ"` (само ако StartCount > 0)
- `ListPage` сигнатура: `(media []web.MediaWithStats, statusFilter, diskFilter, sortFilter string)`
- 4 нови sort-бутона в `.top-nav` (по стил на filter-btn): Аз↑ (name), ▶↑ (last_started), +↑ (added), ✓↑ (marked)

### Тестове
- Нови unit тестове в `handlers_test.go`: сортиране по name, last_started, added
- Нови goquery тестове в `handlers_goquery_test.go`: sort бутони рендират се; "Стартирана N пъти" се появява в row
- E2E: `tests/e2e/test_sort.py`

## Архитектурно решение

Агрегацията (`MAX`, `COUNT`) се изпълнява в SQL (2 заявки общо, не N+1), а сортирането — в Go. sqlc не се използва за stats заявките, защото не може да инферира типа на `MAX(timestamp)` в LEFT JOIN. Вместо това — ръчен `*sql.DB` код с `interface{}` scanning и helper `toNullTime()`.

## Дефиниция за готово

- `task generate` → без грешки
- `task test` → всички тестове минават (вкл. нови)
- `task build` → без грешки
- `/?sort=last_started` показва медии с най-нова дата на стартиране първи
- `/?sort=added` показва най-нови добавени първи
- Row показва "Стартирана N пъти, последно на X" ако е стартирана
- HTMX row update след start/status запазва stats информацията
