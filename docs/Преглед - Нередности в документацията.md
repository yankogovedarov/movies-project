## 3. Несъответствие: Конфигуриран файл за excluded папки

### Проблем
**Проект филми.md, ред 213-217:**
> "Списъкът с папки за пропускане **не е hardcoded в кода**, а в конфигурационен файл, който потребителят може да редактира."

**Факт:** В кода (handlers.go, Scan handler) папките **са hardcoded**:
```go
excludedDirs := []string{
    "$RECYCLE.BIN",
    "System Volume Information",
    // ...
}
```

**Гранични случаи.md, ред 25** също говори за:
> "Потребителят случайно изтрива конфигурационния файл (списъкът с изключени папки) от диска."

Това предполага че трябва да има конфигурационен файл, което не е вярно.

### Действие
Избор между две опции:
1. **Обновете документацията** — признайте че за MVP-1 папките са hardcoded, и планирайте конфиг файл за MVP-2
2. **Имплементирайте конфиг файл** — преместете excluded папките в конфигурационен файл (задача за Итерация 14-15)

### Приоритет
Висок (документацията е противоречива)
